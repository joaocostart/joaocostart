SITE PESSOAL — GITHUB PAGES + CLOUDFLARE (sem servidor proprio)
===============================================================
Como funciona:
  - joaocostart.com        -> GitHub Pages. O GitHub Actions (.github/workflows/pages.yml)
                              gera o site com build_static.py a cada alteracao no main
                              e publica-o (1-2 minutos). Traducao para ingles incluida.
  - joaocostart.com/admin  -> o admin. Quando publicas algo, o proprio browser grava os
                              ficheiros no GitHub (static/admin-shim.js) e o Actions
                              atualiza o site. As estatisticas sao calculadas no browser.
  - api.joaocostart.com    -> Cloudflare Worker (pasta worker/) + base de dados D1:
                              comentarios, registos, visitas, notificacoes (ntfy, WhatsApp,
                              push), etiquetas, links personalizados e utilizadores.
  Tudo gratuito. Nada depende de um computador ligado.

Ficheiros: app.py (so para gerar o site e testar no computador), build_static.py,
translate.py, geo.py, webpush.py, static/ (site e admin), data/ (conteudos),
worker/ (API). A pasta docs/ e gerada (nao vai para o git).

ENTRAR NO ADMIN (joaocostart.com/admin)
  - Password do admin: a que esta no Worker (segredo ADMIN_PASSWORD).
  - Token do GitHub (so na 1.a vez em cada browser):
    github.com -> Settings -> Developer settings -> Personal access tokens ->
    Fine-grained tokens -> Generate new token
      Repository access: Only select repositories -> joaocostart/joaocostart
      Permissions -> Repository permissions -> Contents: Read and write
    Guarda-o num sitio seguro; se o perderes, crias outro.

WORKER (so quando mudares o codigo em worker/)
  cd worker
  npx wrangler login                 (uma vez por computador)
  npx wrangler deploy
  Mudar a password do admin:  npx wrangler secret put ADMIN_PASSWORD
  Base de dados (primeira vez): npx wrangler d1 execute site --remote --file=schema.sql
  Testar no computador: crie worker/.dev.vars com ADMIN_PASSWORD=teste e corra npx wrangler dev

TESTAR O SITE NO COMPUTADOR
  pip install flask cryptography
  ADMIN_PASSWORD=teste python app.py   -> http://localhost:8000
  python build_static.py               -> gera docs/ como no GitHub Actions

VIDEOS
  O GitHub nao aceita ficheiros com mais de 100 MB (e acima de ~50 MB fica lento).
  Comprime antes de publicar (720p, ~2-4 MB por minuto):
  ffmpeg -i original.mov -vf scale=-2:720 -c:v libx264 -crf 24 -c:a aac -movflags +faststart saida.mp4
  Formatos aceites: jpg png webp gif | mp4 webm m4v | mp3 m4a ogg wav
