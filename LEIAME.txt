SITE PESSOAL — GITHUB PAGES + RASPBERRY PI
==========================================
Como funciona:
  - joaocostart.com      -> GitHub Pages (pasta docs/ deste repositorio). E o que os
                            visitantes veem: paginas, escritas, posts, imagens, ingles.
                            Fica sempre online, mesmo com o Pi desligado.
  - api.joaocostart.com  -> o Raspberry Pi (app.py), via Cloudflare Tunnel. Trata dos
                            comentarios, registos, visitas, notificacoes e do /admin.
                            joaocostart.com/admin reencaminha para aqui.
  - Quando mudas algo no admin, o Pi gera de novo a pasta docs/ (build_static.py) e faz
    push para o GitHub (publish.py). O site atualiza 1-2 minutos depois.
  - Com o Pi desligado: o site continua online; comentarios e admin ficam parados.

Ficheiros: app.py (servidor), geo.py, webpush.py, translate.py, publish.py,
build_static.py, static/ (site e admin), data/ (conteudos), docs/ (gerado, nao editar).

1) GITHUB PAGES (uma vez)
   github.com/joaocostart/joaocostart -> Settings -> Pages
   Source: "Deploy from a branch", Branch: main, pasta /docs -> Save
   Custom domain: joaocostart.com (vem do ficheiro docs/CNAME)
   Depois do DNS (passo 2) estar ativo: marcar "Enforce HTTPS".

2) DNS NA CLOUDFLARE (uma vez)  dash.cloudflare.com -> joaocostart.com -> DNS
   - Apaga o registo A antigo de joaocostart.com (o IP de casa).
   - Cria 4 registos A, nome "@", Proxy status "DNS only" (nuvem cinzenta):
       185.199.108.153   185.199.109.153   185.199.110.153   185.199.111.153
   - Cria um CNAME, nome "www", destino joaocostart.github.io, "DNS only".
   - O registo api.joaocostart.com e criado pelo Cloudflare Tunnel (passo 5).

3) INSTALAR NO PI
   sudo apt update && sudo apt install -y git python3-flask python3-cryptography gunicorn ffmpeg
   git clone git@github.com:joaocostart/joaocostart.git ~/site   (depois do passo 4)
   Os segredos e dados privados nao estao no git (ver .gitignore): login Google/Facebook
   e notificacoes configuram-se de novo no admin.

4) AUTORIZAR O PI A FAZER PUSH (publicacao automatica)
   ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
   cat ~/.ssh/id_ed25519.pub
   GitHub -> repositorio -> Settings -> Deploy keys -> Add deploy key
     cola a chave, marca "Allow write access".
   cd ~/site && git config user.name "Site (Pi)" && git config user.email "site@joaocostart.com"

5) CLOUDFLARE TUNNEL (api.joaocostart.com, sem abrir portas no router)
   O tunel "site-api" ja existe na Cloudflare, com a rota
   api.joaocostart.com -> http://localhost:8000 (gerido no painel, nao no Pi).
   dash.cloudflare.com -> Networking -> Tunnels -> site-api -> Overview -> Add a replica
   escolhe Debian e a arquitetura do Pi (64-bit = arm64): a pagina mostra os comandos
   para instalar o cloudflared e o comando final
     sudo cloudflared service install <TOKEN>
   Copia-o de la (o token e secreto: nao o partilhes nem o ponhas no git).
   O tunel antigo "raspberry-site" (criado no Pi antigo, chave perdida) pode ser apagado.

6) ARRANCAR O SITE SEMPRE QUE O PI LIGA
   sudo nano /etc/systemd/system/site.service  (troca UTILIZADOR e a password):

   [Unit]
   Description=Site pessoal
   After=network-online.target
   [Service]
   User=UTILIZADOR
   WorkingDirectory=/home/UTILIZADOR/site
   Environment=ADMIN_PASSWORD=escolhe-uma-password-forte
   Environment=AUTO_PUBLISH=1
   ExecStart=/usr/bin/gunicorn -w 1 --threads 8 --timeout 900 -b 127.0.0.1:8000 app:app
   Restart=always
   [Install]
   WantedBy=multi-user.target

   sudo systemctl enable --now site
   Admin: https://api.joaocostart.com/admin (ou joaocostart.com/admin)
   Registo das publicacoes: data/publish.log

7) TESTAR NO COMPUTADOR (sem Pi)
   ADMIN_PASSWORD=teste python3 app.py   -> http://localhost:8000 e /admin
   python3 build_static.py               -> gera docs/ a mao (faz commit e push depois)

8) VIDEOS
   O GitHub nao aceita ficheiros com mais de 100 MB. Comprime antes de publicar
   (720p, ~2-4 MB por minuto):
   ffmpeg -i original.mov -vf scale=-2:720 -c:v libx264 -crf 24 -c:a aac -movflags +faststart saida.mp4
   Formatos aceites: jpg png webp gif | mp4 webm m4v | mp3 m4a ogg wav
