SITE PESSOAL — GITHUB PAGES + CLOUDFLARE (sem servidor proprio)
===============================================================
Como funciona:
  - joaocostart.com        -> GitHub Pages, gerado por build_static.py no GitHub Actions
                              (.github/workflows/pages.yml). Traducao para ingles incluida.
  - joaocostart.com/admin  -> o admin. So pede a password (criada na 1.a entrada).
                              O que publicas fica guardado no Worker; de 5 em 5 minutos o
                              GitHub Actions vai busca-lo (sync_content.py), guarda-o no
                              repositorio e publica o site. Aparece no site em 5-20 minutos.
  - api.joaocostart.com    -> Cloudflare Worker (pasta worker/) + D1 + KV: conteudo novo,
                              comentarios, registos, visitas, notificacoes, links, utilizadores.
  Tudo gratuito, sem tokens e sem nenhum computador ligado.
  Importante: o conteudo (data/*.json) muda-se pelo admin. Alteracoes feitas a mao nesses
  ficheiros sao substituidas pela versao do admin na sincronizacao seguinte.

Ficheiros: app.py (so para gerar o site e testar no computador), build_static.py,
translate.py, geo.py, webpush.py, static/ (site e admin), data/ (conteudos),
worker/ (API). A pasta docs/ e gerada (nao vai para o git).

ENTRAR NO ADMIN (joaocostart.com/admin)
  Na 1.a vez pede para criares a password (minimo 8 caracteres). Depois, so a password.
  Se a esqueceres: no painel da Cloudflare -> Storage & databases -> D1 -> site -> Console:
    DELETE FROM kv WHERE k='admin_pw';
  e volta a abrir o admin para criar uma nova.

WORKER (so quando mudares o codigo em worker/)
  cd worker
  npx wrangler login                 (uma vez por computador)
  npx wrangler deploy
  Base de dados (primeira vez): npx wrangler d1 execute site --remote --file=schema.sql
  Testar no computador: crie worker/.dev.vars com ADMIN_PASSWORD=teste e corra npx wrangler dev
  Agendamento: o GitHub desliga tarefas de 5 em 5 min se o repositorio ficar 60 dias sem
  alteracoes; nesse caso: GitHub -> Actions -> Publicar site -> Enable workflow.

TESTAR O SITE NO COMPUTADOR
  pip install flask cryptography
  ADMIN_PASSWORD=teste python app.py   -> http://localhost:8000
  python build_static.py               -> gera docs/ como no GitHub Actions

VIDEOS
